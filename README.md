Entry for the [make.fun bounty "Fortune in a Pot"](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9): one line, at most 120 characters, telling a houseplant's fortune — kind, funny, and unmistakably about the plant on the windowsill.

## The entry

> A sunbeam has had a crush on you all winter — this week, it finally stays past noon, just for you.

98 characters, inside the 120-character gate. The sunbeam is not just a blessing but a shy admirer: it has watched the plant all winter, and this week it finally stays past noon. Verified by running `main.py` twice from different directories: identical output both times.

## How it runs

`main.py` (Python 3.13) writes exactly that line to `/output/entry.txt`. It takes no input, makes no network calls, and always writes the same bytes.

```sh
python3 main.py
cat /output/entry.txt
```
